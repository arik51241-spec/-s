# Как загрузить сайт на Railway

Проект уже подготовлен для Railway: сборка, запуск, проверка состояния и PostgreSQL для кодов онлайн-комнат настроены.

## Самый простой способ через GitHub

1. Распакуй `sweet16-pixel-arena-railway-source.zip`.
2. Создай пустой репозиторий на GitHub и загрузи в него все файлы из распакованной папки.
3. Открой Railway, нажми **New Project** → **Deploy from GitHub repo** и выбери репозиторий.
4. На схеме проекта нажми **+ New** → **Database** → **PostgreSQL**.
5. Открой сервис с сайтом → **Variables** → **Add Reference Variable**. Добавь `DATABASE_URL` из сервиса PostgreSQL.
6. Нажми **Redeploy**. Таблица для онлайн-комнат создастся сама при первом обращении.
7. Открой сервис сайта → **Settings** → **Networking** → **Generate Domain**. Получишь временный адрес вида `имя.up.railway.app`.

## Подключение своего домена

1. В том же разделе **Networking** нажми **Custom Domain** и введи домен.
2. Railway покажет записи DNS. Добавь их в панели регистратора домена. Обычно нужны `CNAME` и проверочная `TXT` запись.
3. Дождись подтверждения. Обновление DNS иногда занимает от нескольких минут до 72 часов.

## Что уже настроено

- Команда сборки: `npm run build`.
- Команда запуска: `npm start`.
- Проверка работы: `/api/health`.
- Сервер слушает порт, который Railway выдаёт автоматически.
- Коды онлайн-комнат хранятся в PostgreSQL и удаляются из использования через 6 часов.
- Если запустить сайт локально без `DATABASE_URL`, комнаты временно хранятся в памяти. На Railway обязательно подключи PostgreSQL.

## Локальная проверка

Нужен Node.js 22 или новее.

```text
npm install
npm run dev
```

Открой `http://localhost:3000`.

## Если онлайн-игрок не соединяется

Игра использует прямое WebRTC-соединение и публичный STUN-сервер. В большинстве домашних и мобильных сетей этого достаточно. В очень закрытых сетях может понадобиться отдельный TURN-сервер; сам сайт и комнаты Railway при этом продолжат работать.
